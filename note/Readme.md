# 필기하는 방법

마크다운(Markdown)이라는 방식으로 필기를 쉽게 알아보도록 정리할 수 있습니다!

# 제목(heading)

필기를 할 때 사용하는 제목을 작성하는 방법이며, 해시(#)를 사용합니다.
해시는 1개부터 6개까지 사용 가능합니다.

```
# 대주제
## 소주제
### 세부제목
```

# 리스트(list)

번호를 붙이거나, 점 표시를 해서 항목을 정리할 때 사용

### 앞으로 배울 내용들
- 프론트엔드
- 백엔드
- 인프라
- 데이터베이스

### Github 가입순서
1. 가입버튼을 누른다
2. 정보를 입력한다
3. 캡챠 퀴즈를 푼다
4. 인증번호를 입력한다
5. 가입을 완료한다

# 링크(link)

클릭을 통해 다른 페이지로 이동할 수 있는 글자를 만들 수 있다.  
네이버로 이동하시려면 [여기](https://www.naver.com/)를 누르세요

```
[보여줄글자](이동할주소)
```
